## Node Metrics

**Panel Layout:**
```
Row 1: Overview (CPU, Memory, Disk, Network mini-graph)
Row 2: CPU Usage | Load Average
Row 3: Memory Graph | Memory Gauge | Disk Gauge
Row 4: Disk I/O | Disk Space
Row 5: Network RX | Network TX
```

## Container Metrics

**Panel Layout:**
```
Row 1: Overview (Running Containers, Total CPU, Total Memory, Network Graph)
Row 2: CPU Usage Graph
Row 3: Memory Usage Graph, Memory Cached Graph
Row 4: Network RX | Network TX | Network Errors Graph
Row 5: Disk I/O | Disk Read Graph | Disk Write Graph
Row 6: Container Info & Health
```

## Log Search

**Panel Layout**
```
Row 1: Overview (Total Logs, Error Count, Warning Count, Active Containers)
Row 2: Log Level Analytics | Error & Warning Rate Graph
Row 3: Log Rate Analysis | Log Volume
Row 4: Log Metrics
Row 5: Error Analysis
Row 6: Log Search & Viewer
```
